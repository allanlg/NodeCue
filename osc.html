OSC commands

Connect Node:Cue to controllers, automation systems, and other production tools over the network.

Setup and conventions

Configure OSC input in Configuration > OSC. Add a receive endpoint, select the network interface, set its port, then send commands to that IP address and port.

  • Addresses are lowercase and start with /nodecue.
  • Values are sent as OSC arguments.
  • A first trigger argument of false, 0, 0.0, or nil is ignored.
  • Fade commands accept an optional duration in milliseconds as their first argument.
  • Pad and bus targets can be included in the address or sent as the first argument.

Bus control

Bus IDs are zero-based: 0 Cuelist, 1 Pads, and 2 Playlist.
