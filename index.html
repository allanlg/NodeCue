A programmed sequence for the show rundown.

Build the conduite in its intended order, arm the next cue, and keep every timed or control action visible while the show runs.

  • Audio, Stop, MIDI, and OSC cues
  • Pre-wait, post-wait, loop, and play-next
  • Trim, fades, crossfades, EQ, and compression

Audio routing

One workspace. Three independent buses.

Send each playback family where the production needs it, including separate output devices and channel mappings.

Bus 01 / Cuelist Sequential cue list

The programmed conduite: audio, control cues, waits, and timed transitions in a precise order.

Bus 02 / Pads On-demand pad bank

Independent playback fired outside the sequence, from a jingle to an unplanned live cue.

Bus 03 / Playlist Integrated playlist player

Continuous music playback with automatic transitions to or from the programmed cues.

Primary / Backup Sync

Keep a second machine ready to take control.

Run the show from the Primary while a read-only Backup mirrors project changes, transport actions, and live playback over the production network.

Node:Cue / Primary
Operator control

The authoritative instance accepts show commands and sends each committed action to the Backup.

Synced Project / transport / state
Node:Cue / Backup
Live mirror

The Backup follows in read-only mode and plays locally in parallel, ready at the current show position.

Primary lost If the Primary PC or app crashes, the Backup automatically leaves read-only mode and becomes an immediately operable Standalone instance, preserving current playback so the operator can continue the show.

Audio-path switching remains under the operator's console, matrix, or hardware redundancy system.

Control surfaces

Meet the control system already on the show.

Node:Cue stays operable from its main interface while extending control to the devices and protocols used around it.

MIDI
Map physical controls to show actions.

Trigger transport, pads, cues, and application commands from MIDI input.

OSC
Integrate over the production network.

Send and receive control messages using configurable endpoints and documented commands.

Keys
Keep essential actions under the operator's hands.

Assign shortcuts globally or directly to pads without changing the current view.

Deck
Operate from Elgato Stream Deck.

Use the Node:Cue plugin for compact tactile access to live controls.

DSP
Shape material without leaving the cue.

Per-item EQ and compression stay visible beside the waveform and live analysis.
