Playback Flow / Cross-view control

FLOW is at the core of Node:Cue.

Automate transitions between Cuelist, Pads, and Playlist for more precise and responsive sequences. FLOW manages what stops, what fades, and what keeps playing.

It reduces manual work at the mixing console by handling playback priorities and transitions between the three views.

Audio routing

Route each playback view where it needs to go.

Each playback view has its own routable bus. Send each signal to its own audio device and channel mapping, then mix the three sources separately.

Bus 01 / Cuelist Planned cue sequence

The planned show sequence: audio, control cues, waits, and timed transitions in a precise order.

Bus 02 / Pads Jingles and sound effects

Playback outside the main sequence, from a jingle to an unplanned live cue.

Bus 03 / Playlist Background music

Event ambience for the time before, during, and after the show.

Primary / Backup Sync

Keep a second machine ready to take control.

Run the show from the Primary while a read-only Backup mirrors project changes, transport actions, and live playback over the production network.

Node:Cue / Primary
Operator control

The Primary instance accepts show commands and sends each committed action to the Backup.

Synced Project / transport / state
Node:Cue / Backup
Live mirror

The Backup follows in read-only mode and plays locally in parallel. It is ready to take over if the Primary computer has a bad day.

Primary lost If the Primary computer loses power, gets unplugged, or otherwise drops out of the show, the Backup automatically leaves read-only mode and becomes an immediately operable Standalone instance, preserving current playback so the show can go on uninterrupted.

Audio-path switching remains under the operator's console, matrix, or hardware redundancy system.

Control surfaces

Control Node:Cue and external devices.

Send MIDI and OSC commands from Node:Cue to external devices, and receive MIDI and OSC input to control Node:Cue. The included Stream Deck plugin provides direct access to live controls.

MIDI
Send and receive MIDI control.

Use Node:Cue to trigger external equipment, or use MIDI input to control transport, pads, cues, and application commands.

OSC
Send and receive OSC control.

Exchange control messages with devices and software over the production network.

Keys
Control Node:Cue from the keyboard.

Assign shortcuts to transport, pads, cues, and application commands without changing the current view.

Deck
Use the included Node:Cue Stream Deck plugin.

Trigger transport, pads, cues, and other live controls directly from Stream Deck.
